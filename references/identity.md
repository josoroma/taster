# Taster identity

Use this when explaining Taster itself or extending its showcase. These tokens come from `assets/showcase/showcase.css`; the logo is `assets/showcase/logo.svg`. Other subjects can have their own visual language.

| Role | Value |
| --- | --- |
| Paper | `#f3f2eb` |
| Ink | `#273026` |
| Dark surface | `#1b231d` |
| Lime accent | `#d9ed92` |
| Muted text | `#697064` |
| Hairline | `#d6d8cc` |
| Body and interface | DM Sans, local `assets/fonts/dm-sans-*.ttf` |
| Expressive display | Italiana, local `assets/fonts/italiana.ttf` |
| Small technical labels | System monospace |

Pair a direct sans-serif statement with an occasional Italiana phrase. Use generous space, fine rules, numbered stages, and one accent for the current idea. Lime is a fill or highlight with dark text, not small text on paper. Keep labels legible at the actual export size. The voice is curious and concrete: “Big ideas. Made explorable.”

Use the existing SVG wordmark rather than substituting a new symbol. Copy fonts with their OFL notices and the logo into independent projects. Avoid loading external fonts during playback or capture; wait for local fonts and images before rendering video frames or serializing a diagram export.
