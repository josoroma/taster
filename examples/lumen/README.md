# Lumen — The Sunken Garden

A complete, small browser adventure included in `examples/lumen/`. Explore a handcrafted procedural 3D water garden as a mechanical keeper, restore three ancient beacons, avoid the sentinels, and reopen the gate.

[Play Lumen](https://josoroma.github.io/taster/examples/lumen/) in a browser with WebGL 2.

## Run the source

Requires Node.js 22+. Run these commands from the repository root:

```sh
npm install
npm start
```

Open the address printed by the server and choose **Lumen** from the example catalog. To use a different port, run `PORT=8080 npm start`.

## How to play

- **WASD / arrow keys:** walk relative to the camera. You can also click or tap the courtyard to move.
- **E / Tune:** beside a beacon, catch the moving marker inside the gold band. Each beacon needs three notes, with one note per cycle.
- **Space / Dash:** move quickly through a sentinel without taking damage. The meter shows when dash is ready again.
- **Escape:** pause or resume. The menu also contains rendering quality, gentle motion, and restart.
- Restore all three beacons, then approach the circular gate and tune it to finish.

Touch screens have a direction pad and Tune/Dash buttons. Sound is optional and starts muted. The best completion time is stored only in the browser; there is no account or backend.

## Build and verification

```sh
npm test
npm run build
```

The root `dist/` contains the static examples with local fonts and rendering modules. Serve that directory over HTTP and open `examples/lumen/`; the build can be hosted at the root or under a directory such as `/taster/`. Opening `index.html` directly as a `file://` URL is not supported because the game uses JavaScript modules.

The deterministic game tests cover timing, all nine beacon notes, collision, dash protection, pause, restart, damage, and a complete route to victory. Browser review also covers actual keyboard and touch input, the win screen, graphics fallback, and desktop/mobile layouts.

Optional browser captures use Chrome or Chromium:

```sh
node scripts/capture.mjs http://localhost:5173/taster/examples/lumen/ --select '#game' --out shots/desktop.png --width 1440 --height 960 --scale 1
node scripts/capture.mjs http://localhost:5173/taster/examples/lumen/ --select '#game' --out shots/mobile.png --width 390 --height 844 --scale 1
```

Set `CHROME_PATH` if Chrome is not detected. Capture helpers require no npm dependencies. `--select '#game'` captures the complete game instead of selecting the small SVG logo.

## Implementation

The scene is built from procedural meshes, instanced foliage and masonry, local surface textures, custom animated water, physical materials, and shadows. The simulation uses a fixed timestep separate from rendering. It is a stylized game world, not a scientific fluid simulation.

- [main.mjs](main.mjs): input, game loop, accessible HTML HUD, sound, and state transitions.
- [src/model.mjs](src/model.mjs): deterministic game rules.
- [src/scene.mjs](src/scene.mjs): Three.js world and animation.
- [style.css](style.css): responsive interface.
- [tests/model.test.mjs](../../tests/model.test.mjs): game-rule regression tests.
