# Mounting plate: real CAD behind the animation

The four stages are separate SMLib B-rep solids generated by **smlibpy 0.3.1**.
They reproduce the small mounting plate shown on the [SMLibPy home page](https://smlibpy.classcad.ch/): stock, corner fillets, four through holes, then a blind pocket.

The model uses millimeters and a right-handed, Z-up coordinate system. Stock is centered on the origin with bounds `[-40,-30,-5]` to `[40,30,5]`. Hole diameter is 8 mm; the center pocket measures 30 × 20 × 4 mm and its floor is at Z = 1 mm.

## Reproduce or edit

From the project root (Taster or a generated Workshop project), run:

```sh
uv run scripts/build-cad-example.py
```

`uv` supplies the pinned library in an isolated environment. No MCP or global configuration is installed. Change the dimensions in [`source.py`](source.py), then rerun the builder to update the browser manifest and exported files. The checks assume the cuts remain separate and within the stock; dimension edits that violate those assumptions must update the model and checks together.

To generate just the CAD files from the standalone source:

```sh
uv run examples/workshop/assets/cad-plate/source.py
```

- [`final.step`](final.step) retains exact B-rep surfaces and millimeter units.
- [`final.stl`](final.stl) is a triangle approximation with 0.025 mm meshing tolerance. STL does not record a unit: import its values as millimeters.
- [`manifest.json`](manifest.json) contains the browser preview and measured properties. Browsing the lesson needs no Python or native CAD kernel.

## Browser manifest contract

Top-level fields include `schemaVersion: 1`, `units: "mm"`, `upAxis: "Z"`, `sourceLibrary`, `sourceVersion`, `meshTolerance`, `parameters`, `stages`, and `validation`.

Each `stages` entry has:

| Field | Meaning |
| --- | --- |
| `id` | `stock`, `fillet`, `holes`, or `pocket` |
| `title`, `code` | Operation label and executable SMLibPy operation |
| `volume`, `area`, `centerOfMass` | B-rep-derived measures in mm³, mm², and mm |
| `faces`, `topologicalEdges`, `valid` | Kernel topology counts and validity result |
| `bounds.min`, `bounds.max` | XYZ corners of the kernel bounding box |
| `positions` | Flat indexed vertex coordinates, `[x,y,z,…]` |
| `indices` | Flat triangle vertex indices, `[a,b,c,…]` |
| `edges` | Array of flat XYZ polylines sampled from actual B-rep edges |
| `edgeTypes` | Corresponding kernel curve types |
| `meshVolume`, `meshClosed` | Preview mesh validation, distinct from exact-solid measures |

The renderer should depth-test edges against the solid triangles to hide occluded lines. Periodic surface seams are omitted by `part.edges()`; `topologicalEdges` may therefore exceed the number of drawn polylines. Each curved polyline uses a chord-error bound of 0.025 mm. Renderer-computed normals are appropriate for a preview; they are not surface-analysis data. Do not interpolate triangle indices between operations: topology changes. A crossfade or an illustrative cutting tool may bridge completed feature states.

## Verification

The generator checks all four B-reps are valid, display meshes are closed with positive volume, and cutting operations decrease volume. It checks the final volume against a separate closed-form calculation, probes the exact body to verify the 4 mm pocket depth and all four open holes, and reads the exported STEP back with healing disabled. The STEP round trip must preserve validity, face count, volume, and bounding box. The exported STL must remain closed and agree with the exact volume within 0.2%.

The measured stage volumes are 48,000; 47,450.6192983; 45,440; and 43,040 mm³. Face counts are 6, 10, 14, and 19. These values are outputs of the generator, not labels hard-coded into the viewer.

This is an instructional model. No material, manufacturing tolerance, fit, printer settings, strength calculation, or robot safety analysis is specified. A CAD-valid solid alone does not establish those properties.
