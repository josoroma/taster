ABOUT THIS STUDY

A drawing of
a real solid.

This plate is constructed by Python using SMLibPy. Each of the four states is exported from the CAD kernel, including its measured volume and face count. The browser draws a triangle mesh and edge curves from those states; it does not run a CAD kernel.

The sequence selects complete, discrete construction states. It shows what each modeling operation changes, rather than simulating material removal, tool motion, or a 3D printer. All dimensions are in millimeters.

The downloadable STEP file contains the final CAD solid. The STL is a tessellated surface and does not encode units. Use millimeters when importing it, and choose manufacturing settings separately.
